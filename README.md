# Unsent: The Micro-Confession Sprint

[![make.fun](https://make.fun/badge.svg)](https://make.fun/c/u-boothlord-unsent-the-micro-confession-sprint-8c6596ba)
[![Unsent: The Micro-Confession Sprint](https://make.fun/c/u-boothlord-unsent-the-micro-confession-sprint-8c6596ba/badge.svg)](https://make.fun/c/u-boothlord-unsent-the-micro-confession-sprint-8c6596ba)

Entry for the [Unsent: The Micro-Confession Sprint](https://make.fun/c/u-boothlord-unsent-the-micro-confession-sprint-8c6596ba) bounty on [make.fun](https://make.fun).

`main.ts` writes one two-part micro-confession to `entry.txt`: a `To:` line
naming who it was meant for, then the unsent line itself, exactly as typed
and never sent — 177 characters, inside the 1–260 gate.

Run: `node main.ts` (Node 22.18+). Output goes to `$MAKEFUN_OUTPUT_DIR/entry.txt`, or `/output/entry.txt` when unset.
